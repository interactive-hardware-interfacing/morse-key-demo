About this demo

What it shows

Before text messages there was Morse code: press a key short for a dot, long for a dash, and the gaps between presses separate the letters. Here you key it in and the computer decodes it live — and the same page works three ways, so it always has something to show.

Three ways to drive it:

  • Wired — a key and buzzer on one board plugged into the laptop.
  • Wireless — key on a remote board, received by a bridge across the room.
  • Keyboard — no hardware at all: hold the spacebar. Great as a backup if a board dies mid-tour.

Try this during the tour: tick Keyboard mode and tap · · ·　— — —　· · · (SOS). Then hand a student the real key and have them send their initials.

How it works

The board reports clean key edges — “down at t”, “up at t” — over USB. All the timing lives in this page: a press shorter than about two dits is a dot, longer is a dash; a gap of about three dits ends a letter, seven ends a word. The dit length slider sets the pace. Keyboard mode feeds the exact same decoder from your spacebar. Edge line format is in PROTOCOL.md.

Known quirks:

  • Decoding depends on rhythm. If letters run together, raise the dit length; if everything reads as dashes, lower it.
  • The buzzer is a passive piezo on a GPIO — a plain on/off tone, not a pure sine. Fine for the room.
  • Wireless setup: both boards pin channel 6, antennas clipped on.
  • Set the D8 jumper before power-up — the role is read once at boot.
  • Flashing stuck? Hold BOOT, tap RESET, release BOOT.

Put the firmware on the boards

One file, firmware/code.py, on every board. The role is picked by a jumper at boot — no editing.

  1. Install CircuitPython on each XIAO ESP32-C3 if needed (board page).
  2. Copy firmware/code.py to each board.
  3. Wired: one board with a button on D1 and a buzzer on D3, plugged into the laptop. Done.
  4. Wireless: one board as the key (button on D1), and a second as the bridge — add a buzzer on D3 and a jumper from D8 to GND, plug the bridge into the laptop.
  5. Connect (for wired/wireless): click Connect bridge and pick the USB JTAG/serial port. Or just tick Keyboard mode and use the spacebar.
