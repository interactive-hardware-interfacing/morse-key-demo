Hardware

Which boards, which pins, and the one jumper that picks a board’s job.

Three setups

Wired1× Seeed XIAO ESP32-C3, plugged into the laptopPushbutton on D1, piezo buzzer on D3
Wireless2× XIAO ESP32-C3, both with u.FL antennasKey board: button on D1, USB-bank powered. Bridge board: buzzer on D3, jumper D8→GND, plugged into the laptop
KeyboardnoneJust a browser — hold the spacebar

One firmware file on every board. A jumper from D8 to GND at boot makes a board the wireless bridge; no jumper makes it a key, which is also the right role for the single wired board.

Parts

  • Seeed XIAO ESP32-C3 — one for wired, two for wireless — with the u.FL antenna that ships with it.
  • A momentary pushbutton (any tactile switch works; a real straight key is more fun).
  • A passive piezo buzzer.
  • For the bridge: a jumper wire or 2-pin header shunt between D8 and GND.
  • USB-C data cables (not charge-only) and, for the remote key, a USB power bank.

Things that bite

  • Set the D8 jumper before power-up — the role is read once at boot.
  • Both wireless boards pin Wi-Fi channel 6 and need their antennas clipped on; range without an antenna is a few feet.
  • A board that won’t take firmware: hold BOOT (B), tap RESET (R), release BOOT, then try again.
  • If the chooser shows no port, the cable is the usual suspect — many USB-C cables are charge-only.

Pinout detail and a parts list are in wiring/wiring.md.

Put the firmware on the boards

One file, firmware/code.py, on every board, written straight from this page. Chrome or Edge.

1. Plug in

Connect one XIAO ESP32-C3 over USB. If the instrument is connected to a board, this page disconnects it first.

2. Install

Click Install firmware and pick the board’s port (USB JTAG/serial debug unit). The page writes code.py over CircuitPython’s REPL, checks its size and CRC on the board, reboots it, and waits for the firmware’s first line.

3. Repeat

For the wireless setup, do the same on the second board. The firmware is identical; the D8→GND jumper on the bridge picks its role at boot.

4. Connect

Back on the instrument, click Connect bridge and pick the same port. Or skip all of this: tick Keyboard mode and use the spacebar.

Ready. Plug a board in and click Install.
No CircuitPython on that board. A XIAO ESP32-C3 fresh from the bag runs Seeed’s factory sketch, not CircuitPython. Install CircuitPython once with the button below, then come back to Install firmware.

About this demo

What it shows, how to run it in front of a room, and how the decoding works.

What it shows

Before text messages there was Morse code: press a key short for a dot, long for a dash, and the gaps between presses separate the letters. Here you key it in and the computer decodes it live — and the same page works three ways, so it always has something to show.

  • Wired — a key and buzzer on one board plugged into the laptop.
  • Wireless — key on a remote board, received by a bridge across the room.
  • Keyboard — no hardware at all: hold the spacebar. Great as a backup if a board dies mid-tour.

Try this during the tour: tick Keyboard mode and tap · · ·　— — —　· · · (SOS). Then hand a student the real key and have them send their initials.

How it works

The board reports clean key edges — “down at t”, “up at t” — over USB. All the timing lives in this page: a press shorter than about two dits is a dot, longer is a dash; a gap of about three dits ends a letter, seven ends a word. The dit length slider sets the pace. Keyboard mode feeds the exact same decoder from your spacebar. The edge line format is in PROTOCOL.md.

Known quirks:

  • Decoding depends on rhythm. If letters run together, raise the dit length; if everything reads as dashes, lower it.
  • The sidetone from the page is a sine wave; the buzzer on the board is a plain on/off piezo tone. Both are fine for the room.
  • Audio only starts after you tick the Audio box — browsers won’t play sound before a click.
